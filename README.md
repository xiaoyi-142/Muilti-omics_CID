# Multi-omics analysis of chronic insomnia disorder

This repository contains the analysis code for the study:

**“Integrated analyses of gut microbiota, serum metabolites, and brain function reveal dysregulation of the microbiota–gut–brain axis in chronic insomnia.”**

The study integrates gut metagenomics, serum metabolomics, resting-state functional MRI, and clinical data to investigate alterations of the microbiota–gut–brain axis in chronic insomnia disorder (CID).

## Requirements

Main analyses were performed using **R** and **MATLAB**.

Major R packages include:

* `vegan`
* `phyloseq`
* `microbiomeMarker`
* `tidyverse`
* `ggplot2`

Functional gradient analyses were performed using the **BrainSpace** toolbox in MATLAB.

## A brief description of the contents

### Metagenomics

Scripts for species-level microbial analysis and KEGG functional profile analysis, including differential abundance analysis, LEfSe, and multivariate analyses.

### Metabolomics

Scripts for differential metabolite analysis, global metabolomic profile analysis, KEGG annotation, and metabolic pathway analysis.

### Neuroimaging

Scripts for resting-state functional connectivity and functional gradient analyses using BrainSpace.

## Data availability

Participant-level data are not included in this public repository because of privacy and ethical restrictions. Processed data may be available in accordance with the data-sharing statement of the associated publication.
